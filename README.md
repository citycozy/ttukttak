## ⚙️ 사용 기술 
#### • Backend  
  Java, Spring Boot, Spring JPA, Spring Security
#### • Database  
  MariaDB  
#### • Documentation  
  Swagger UI   
#### • DevOps 
  Gradle 
#### • OpenAPI
  KaKaoMap, Toss Payments
